# Фундація майбутнього держави — сайт (HTML/CSS/JS)

Односторінковий адаптивний сайт на **чистому HTML, CSS та JavaScript — без збірки й без npm**; медіаблоки лаб. 7 (відео, інформер, карта) зверстано Tailwind CSS через Play CDN. Відкривається напряму в браузері і публікується на GitHub Pages без жодних build-кроків. Живі версії: [GitHub Pages](https://angelinaua15-bit.github.io/Future-State-Foundation-website/) і [Vercel](https://future-state-foundation-website.vercel.app).

## Як подивитись локально

Просто відкрийте `index.html` подвійним кліком у браузері — сайт повністю самодостатній.

Якщо браузер блокує `fetch`/шрифти при відкритті файлу напряму (рідко буває через локальні CORS-обмеження), запустіть будь-який простий локальний сервер:

```bash
python3 -m http.server 8080
# або
npx serve .
```

і відкрийте `http://localhost:8080`.

## Як викласти на GitHub

1. Створіть новий репозиторій на GitHub (Public, без README/gitignore — вони вже є тут).
2. У цій папці:
   ```bash
   git init
   git add .
   git commit -m "Init: сайт фундації"
   git branch -M main
   git remote add origin https://github.com/<ваш-акаунт>/<назва-репо>.git
   git push -u origin main
   ```
3. Щоб отримати живе посилання — **GitHub Pages**:
   - Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
   - Через 1–2 хвилини сайт буде доступний на `https://<ваш-акаунт>.github.io/<назва-репо>/`.

Ніякого build-кроку тут немає, тому не буде повторення історії з v0/Vercel — GitHub Pages просто роздає файли як є.

## Лаб. 11: інтерактивний віджет і Edge Cases

Секція [«Калькулятор волонтерського часу»](https://future-state-foundation-website.vercel.app/#calculator): користувач обирає години на тиждень (1–40), тривалість (1 / 3 / 6 / 12 міс.), участь у подіях (+4 год/міс.), інструктаж (+2 год), кількість друзів (0–5) — і миттєво бачить загальний внесок, середнє за місяць і розбивку. Формула: `тижні = round(міс. × 52 / 12)`, `основні = години × тижні`, `разом = основні + події + інструктаж + друзі × основні`.

- Логіка — `assets/js/widget.js` (Vanilla JS, IIFE без глобальних змінних). Кожен `[data-volunteer-calc]` — окремий екземпляр, частини шукаються через `data-vc` усередині кореня.
- Захисне програмування: HTML5 `min` / `max` / `step` / `required` + перевірка в JS (`Number.isNaN`, `Number.isFinite`, діапазон до округлення, `validity.badInput`, білий список для `select`, межі для `range`), вивід лише через `textContent`; у результат ніколи не потрапляє `NaN`, `Infinity`, від'ємне число чи `-0`.
- Помилки — під полем, класи Tailwind (`tw-…`) додаються й знімаються динамічно, `aria-invalid`, `aria-live`.
- Тексти UA / EN, світла й темна теми, адаптивність 320–1440 px.
- QA: 21 тест-кейс, стрес-тест на 2000 подій, регресійні прогони після кожного виправлення.

## Лаб. 12: аудит, оптимізація і CI/CD

Аудит Lighthouse 13.5 (PageSpeed Insights, Mobile) до оптимізації: Performance 60, Accessibility 97, Best Practices 100, SEO 100 (FCP 4,5 с, LCP 7,7 с). Що змінено:

- **CSS:** Tailwind зібрано заздалегідь (`tailwind.config.js` + `src/tailwind.css` → `assets/css/tailwind.css`, 9 КБ) замість Play CDN (124 КБ JS у `<head>`). Перезбірка: `npx tailwindcss@3.4.17 -c tailwind.config.js -i src/tailwind.css -o assets/css/tailwind.css --minify`.
- **Шрифти:** Onest і Unbounded з власного домену (`assets/fonts`, SIL OFL), `font-display: swap`, `unicode-range`, preload двох основних файлів.
- **Сторонні бібліотеки:** Swiper, Fancybox, Typed.js і їхні CSS підключає `lab10-gallery.js`, коли галерея наближається до екрана; YouTube — «фасад» (обкладинка + кнопка), плеєр вантажиться після кліку.
- **Медіа:** відео Hero стартує після завантаження сторінки (до того — постер), на смартфоні — версія 640×360 (463 КБ замість 1,3 МБ); перестиснуті WebP, логотип 96 px WebP замість PNG 256 px.
- **Перший екран:** без прелоадера на смартфоні; Hero видно одразу, а не після виконання всього JavaScript; калькулятор ініціалізується біля екрана.
- **Доступність:** контраст «незапалених» слів маніфесту (WCAG AA), зони дотику на сенсорних екранах ≥ 48 × 48 px (кнопки шапки, крапки слайдера, «Читати біографію», посилання футера тощо), без горизонтального скролу на 320–412 px.
- **SEO:** canonical, Open Graph з абсолютними URL, JSON-LD (NGO), `robots.txt`, `sitemap.xml`.
- **Безпека:** `vercel.json` — CSP (з SHA-256 інлайн-скрипта), COOP, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy; кешування шрифтів і медіа.
- **CI/CD:** `.github/workflows/deploy.yml` — перевірки якості (актуальність Tailwind-збірки, синтаксис JS, CSP-хеш, robots/sitemap), Lighthouse CI з порогом 0.9 (`lighthouserc.json`), деплой на Vercel.

## Структура проєкту

```
index.html               — уся розмітка сторінки, 10 секцій за ТЗ
assets/
  css/style.css           — усі стилі й анімації (дизайн-токени у :root)
  js/i18n.js               — словник текстів інтерфейсу UA/EN
  js/data.js                — контент: команда, новини, контакти
  js/app.js                  — вся логіка: рендер, i18n і тема, прелоадер, сцени скролу
                                (hero, напрями, новини), конструктор участі, форми, модалка
  js/widget.js             — віджет «Калькулятор волонтерського часу» (лаб. 11)
  css/tailwind.css         — зібраний Tailwind (лаб. 12; джерело — src/tailwind.css)
  fonts/                   — шрифти Onest і Unbounded (лаб. 12)
  img/                       — логотип (кілька розмірів + favicon), фото команди, зображення-заглушки
```

Ніякого бандлера немає навмисно: `app.js` рендерить контент із `data.js`/`i18n.js` у DOM при завантаженні сторінки і при перемиканні мови — досить відкрити код у будь-якому редакторі, усе видно одразу.

## Що реалізовано

- **Структура сторінки**: Header → Hero (з чесними фактами про фундацію) → Про нас (місія за статутом + блок «Як ми влаштовані» з органами управління) → Напрями (8 карток за реальними напрямами статуту, зокрема підтримка ветеранів/військових та ВПО) → Команда (4 картки + модалка з біографією) → Конструктор участі (3 кроки → персональна рекомендація напряму) → Медіа/Новини (карусель із навігацією prev/next та індикаторами-крапками, touch-свайп через scroll-snap) → Контакти → Footer.
  Секції «Проєкти», «Результати» (лічильники фейкових досягнень) та «Партнери» **навмисно прибрані** — фундація щойно заснована (18.08.2026) і ще не має ні реалізованих проєктів, ні підтверджених партнерів, тож на сайті лише перевірювані факти. Коли з'являться перші реальні кейси й партнери — ці секції можна додати назад за тим самим патерном, що й Команда/Медіа.
  Весь текст про місію, напрями діяльності та структуру управління взято безпосередньо зі статуту організації (розділи 3 і 5) — нічого не вигадано.
- **UA/EN** — перемикач у хедері (desktop і mobile), запам'ятовує вибір у `localStorage`, увесь текст продубльовано в `assets/js/i18n.js`.
- **Кольори бренду**: Blue `#00469B`, Yellow `#FEC301`, Dark Blue `#01226B` — визначені як CSS-змінні у `:root` (`assets/css/style.css`).
- **Дизайн і анімації (редизайн 2026-10)** — за мотивами референсу «апертура»:
  - **Прелоадер**: дерево з логотипу малюється лініями (синя ліва половина, жовта права), лічильник 000→100, потім синьо-жовта «шторка» розходиться й відкриває сайт.
  - **Hero**: фото на весь екран (на телефоні — верхні дві третини, щоб воно не збільшувалось і лишалось чітким). Старт: фото відкривається шторкою знизу вгору й «наїжджає» з легкого збільшення, слова слогану виїжджають по черзі, факти — збоку, лічильники рахуються. Під час скролу фото їде повільніше за сторінку, текст м'яко згасає; фото змінюються слайд-шоу.
  - **Про нас**: одна коротка фраза місії, що «загоряється» слово за словом, одне речення пояснення, 4 цінності рядком і структура управління однією лінією (Загальні збори → Правління → Голова).
  - **Напрями**: ліворуч список з власними іконками, праворуч закріплена картка з фото активного напряму (фото змінюється шторкою знизу) — нічого не перекриває кнопки. На телефоні — мініатюра в кожному рядку. Кнопка зі стрілкою веде до конструктора участі й одразу підставляє цей напрям.
  - **Команда**: смуга вертикальних карток, активна розширюється й стає кольоровою; клік — модалка з біографією та фото.
  - **Новини**: стрічка карток сама повільно пливе по колу (зупиняється під курсором), її можна тягнути мишкою чи пальцем з інерцією, є кнопки ← →. Клік по картці відкриває новину повністю у вікні з фото. Сторінку стрічка не «тримає» — скрол звичайний.
  - **Рухомі стрічки** між «Напрямами» й «Командою»: синя з напрямами та іконками і жовта з цінностями біжать назустріч хрестом; **обертовий бейдж** «Долучайтеся до фундації» біля конструктора веде до форми; картки новин і команди злегка нахиляються за курсором.
  - **Футер**: «біжучий рядок» з гаслами, обертові синьо-жовті позначки.
  - Власний курсор і «магнітні» кнопки (лише миша), смужка прогресу скролу в кольорах прапора, меню з «пігулкою» активного розділу.
  - Шрифти: **Unbounded** (заголовки — український шрифт) і **Onest** (текст), обидва з Google Fonts з повною кирилицею.
- **Живий фон** — м'які синьо-жовті кольорові плями повільно пливуть, крапкова сітка і листочки з логотипу піднімаються вгору (`.bg-scene` в `index.html`, стилі — розділ «Живий фон» у `style.css`).
- **Логотип** — векторний (`logoSVG()` в `app.js`): кільце й назва по колу беруть колір теми — темні на світлій, світлі на темній; дерево у фірмових синьому й жовтому. PNG-версія лишилась лише для favicon і як запасний варіант.
- **Заголовки секцій** — великий Unbounded з тісним трекінгом, слова з'являються по черзі «з-під маски»; шапка секції — заголовок ліворуч, пояснення праворуч.
- **Іконки** — власний набір у єдиному стилі: `assets/js/icons.js` (8 напрямів + 4 цінності, з анімацією «малювання»); ті самі іконки статичними файлами — у `assets/img/icons/`.
- **Порядок секцій**: Hero → Про нас → Напрями → стрічки → Команда → Новини → Конструктор участі → Контакти (від знайомства до дії).
- **Мобільні**: сайт завжди відкривається з першого екрана (`history.scrollRestoration = "manual"`), щоб Safari не «кидав» на стару позицію.
- **Продуктивність**:
  - усі фото у **WebP** (≈ на 40% легші за JPG; JPG-оригінали лишились у репозиторії);
  - шрифти Google вантажаться **без блокування** першого малювання; скрипти з `defer`;
  - прелоадер коротший (~1 с) і показується лише при першому заході (повторно — не раніше ніж через 30 хв, `fsf-seen` у `localStorage`);
  - hero коротший (200svh), вікно розкривається через `transform: scale`, без перерахунку радіуса щокадру;
  - без живого розмиття (`backdrop-filter`) під меню й кнопками — воно найбільше навантажувало скрол;
  - кольорові плями фону малюються маленькими й збільшуються через `scale`; під час скролу фонові анімації завмирають, а стрічки й біжучий рядок поза екраном стоять на паузі;
  - розміри секцій кешуються, у циклі скролу лише арифметика й запис `transform`/`opacity`; стрічка новин крутиться лише коли видна.
- **Світла й темна теми** — світла основна; перемикач сонце/місяць у шапці (і в мобільному меню). Нова тема «розливається» колом від кнопки (View Transitions API; у браузерах без підтримки — миттєва зміна). Вибір зберігається в `localStorage` (`fsf-theme`). Кольори обох тем — CSS-змінні у `[data-theme="dark"]` / `[data-theme="light"]` на початку `style.css`.
- Усі анімації вимикаються при `prefers-reduced-motion: reduce` — тоді сцени не закріплюються, а контент показується одразу.
- **Доступність (WCAG)**: skip-link, семантичні `header/main/footer/nav`, видимий фокус (`:focus-visible`), клавіатурна керованість (мобільне меню, модалка команди закривається по Esc і повертає фокус), `fieldset`-подібна група радіо-кнопок у конструкторі участі, `aria-live` на статусах форм, контрастні кольори.
- **Форми**: валідація на чистому JS (ім'я, email, повідомлення, згода на обробку даних) з видимими повідомленнями про помилки, honeypot-поле проти найпростіших ботів.
- **SEO**: `<title>`, `meta description`, Open Graph теги, семантична розмітка.
- **Оптимізовані зображення**: логотип оброблено в кілька розмірів (16/32/180/192/256/512 px) + favicon; усі декоративні зображення — легкі SVG.

## Підключення форм до реального відправлення

Форма зворотного зв'язку та підписка на розсилку надсилають заявки в Telegram-групу через Vercel Function `api/lead.js`. Адреса функції задається в `assets/js/app.js` → `LEADS_ENDPOINT`.

Налаштування у Vercel (**Settings → Environment Variables**, після збереження — **Deployments → Redeploy**):

- `BOT_TOKEN` — токен бота від @BotFather;
- `CHAT_ID` — id групи. Щоб його дізнатися, напишіть будь-що в групу й відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — потрібне число з `"chat":{"id":-100...` (разом з мінусом).

Якщо сайт переїде на інший домен, додайте його в `ALLOWED_ORIGINS` у `api/lead.js` — запити з інших адрес функція відхиляє. Якщо заявки не приходять, причину видно в логах функції: Vercel → **Logs**.

## Технічні вимоги — статус

- Адаптивність (mobile/tablet/desktop) — так, mobile-first, перевірено без горизонтального скролу.
- Доступність (WCAG, керованість з клавіатури) — так, див. вище.
- Валідація форм — так, на чистому JS, з honeypot проти ботів.
- Оптимізовані зображення — так (SVG-заглушки легкі; логотип у кількох розмірах).
- Проста CMS — у цій версії контент лежить у читабельних JS-файлах (`data.js`, `i18n.js`), редагування не потребує знання HTML/CSS, лише текстового редактора. Повноцінна візуальна CMS (наприклад, headless-рішення) — окремий наступний крок, якщо буде потрібен.

7. **Фото напрямів** — у `data.js → directionPhotos` для кожного напряму вказано базовий шлях до фото (без `.jpg`; поруч мають лежати версії `@480w` і `@800w`).
