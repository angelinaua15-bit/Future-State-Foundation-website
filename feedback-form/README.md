# Форма зворотного зв'язку (лаб. 9)

Адаптивна форма для сайту ГО «Фундація майбутнього держави» з клієнтською валідацією на Vanilla JS і регулярних виразах.

- **Жива версія (Vercel):** https://future-state-foundation-website.vercel.app/feedback-form/
- **GitHub Pages:** https://angelinaua15-bit.github.io/Future-State-Foundation-website/feedback-form/

## Структура

```
feedback-form/
├── index.html               # семантична розмітка форми + модальне вікно (Tailwind CSS, Play CDN)
├── assets/css/styles.css    # спільний вигляд полів і UI-стани normal / focus / error / success
├── assets/js/validation.js  # валідація, динамічна перевірка, автоформат телефону, модальне вікно
└── README.md
```

## Правила валідації

| Поле | Тип | Правило | Приклад правильного значення |
|---|---|---|---|
| Ім'я | `text` | 2–60 символів; лише літери, між словами — пробіл, дефіс або апостроф | `Дар'я Ковальська-Бойко` |
| Телефон | `tel` | рівно `+380` і 9 цифр (`/^\+380\d{9}$/`) | `+380501234567` |
| Email | `email` | `name@domain.zone`, без подвійних крапок, зона від 2 літер | `user.name+tag@foundation.org.ua` |
| Повідомлення | `textarea` | 10–1000 символів без урахування пробілів на краях | `Хочу долучитися до волонтерства.` |
| Згода | `checkbox` | обов'язково відмічено | ☑ |

Помилки з'являються після виходу з поля або після спроби надіслати форму; виправлене поле одразу стає зеленим.
Номер `0501234567` автоматично перетворюється на `+380501234567` (з поясненням під полем), пробіли, дужки й дефіси під час вставлення прибираються. Літери ніколи не видаляються мовчки.

## Важливо

Бекенду немає: після успішної перевірки показується вікно «демонстрація клієнтської валідації», дані нікуди не надсилаються.
Клієнтська валідація — це зручність, а не захист: якщо форму підключити до сервера (наприклад, до `api/lead.js`), сервер має перевіряти ті самі правила повторно.

## Локальний запуск

```bash
python3 -m http.server 8080   # у корені репозиторію
# http://localhost:8080/feedback-form/
```
